# MiMoBal

MiMo 余额 / Token Plan 桌面小工具。托盘常驻，悬浮窗让你一眼看到余额和用量，不用打开网页。

## 功能

- **悬浮窗**：核心大数字 + 字段列表，拖动记忆位置，点击数值可复制，支持迷你单行模式
- **托盘**：悬停查看摘要，右键打开菜单；左键打开设置
- **字段自选**：余额、套餐、用量、订阅等字段自由勾选和排序
- **阈值提醒**：字段低于/高于设定值时变红，并发送系统通知
- **自动刷新**：默认 60 秒，可在设置中调整（10 秒 ~ 5 分钟）

## 安装使用

1. 确保电脑上已安装并登录 [MiMo Desktop](https://mimo.xiaomi.com)
2. 到 [Releases](https://github.com/galaxrin/MiMoBal/releases) 下载最新的 `MiMoBal-Setup-*.exe`，双击安装
3. 启动后在系统托盘找到 MiMo 图标即可

**常用操作**

| 想做什么 | 怎么做 |
|---|---|
| 看余额 / 用量 | 看悬浮窗；或悬停托盘图标 |
| 改显示哪些字段 | 托盘左键 → 设置 → 悬浮窗 / 托盘栏 |
| 显示 / 隐藏悬浮窗 | 设置里的「显示悬浮窗」开关 |
| 数据不对 | 悬浮窗或设置里点「重试」 |
| 提示登录失效 | 在 MiMo Desktop 退出并重新登录，再点「重试」 |

## 从源码运行

```bash
npm install
npm start
```

需要 Node.js 22 或以上。
